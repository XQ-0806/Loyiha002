# 📖 GITHUB STORY CHALLENGE

## Hikoya: O‘qituvchim qanday dasturchi bo‘lgan?

### 🎯 Missiya
15 nafar o‘quvchi bitta umumiy hikoyani yaratishi kerak. Har bir ishtirokchi hikoyaning faqat bitta qismini yozadi.

### 📌 Qoidalar

1. Har bir o‘quvchiga alohida savol beriladi.
2. O‘z branch'ingizga o'ting.
3. `hikoya.txt` faylini oching.
4. O‘zingizga tegishli raqamlangan qatorni to‘ldiring.
5. Javobingiz bitta to‘liq va mantiqiy gapdan iborat bo‘lsin.
6. Boshqa o‘quvchilarning qatorlariga tegmang.
7. O‘zgarishlarni Commit qiling.
8. GitHub'ga Push qiling.
9. `main` branchiga Pull Request yuboring.

### ⚠️ Maxsus qoidalar

- Boshqa o‘quvchining branchiga o'tish taqiqlanadi.
- Boshqa o‘quvchining matnini o‘zgartirish taqiqlanadi.
- Hikoyaning keyingi qismini oldindan bilish uchun boshqa o‘quvchilardan so‘ramang.
- Imlo va mantiqqa e'tibor bering.
